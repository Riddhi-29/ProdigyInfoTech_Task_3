# ProdigyInfoTech_Task_3

Decision Tree Classifier – Bank Marketing Dataset

📌 Project Overview
This project is part of Prodigy Infotech’s Data Science Internship – Task 3.
The objective of this task is to build a Decision Tree Classifier to predict whether a customer will purchase a product or service based on their demographic and behavioural data.

For this task, the Bank Marketing Dataset from the UCI Machine Learning Repository was used to analyze customer behavior and model purchase decisions.

🎯 Objective
Load and preprocess a real-world dataset
Perform exploratory data analysis (EDA)
Encode categorical variables for machine learning
Build a Decision Tree classification model
Evaluate model performance using standard metrics
Visualize feature importance and decision rules
🌍 Dataset Details
Dataset Name: Bank Marketing Dataset
Source: UCI Machine Learning Repository
File Used: bank.csv
Target Variable: y (renamed as deposit)
yes → Customer purchased the product
no → Customer did not purchase the product
🔑 Features Include
Demographic Features: age, job, marital status, education
Financial Features: balance, loan, housing
Campaign Features: contact type, duration, campaign, previous outcomes
